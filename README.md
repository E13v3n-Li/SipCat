# SipCat：像素黑猫喝水提醒

四种状态的像素黑猫桌宠：正常眨眼、捧杯喝水、挥爪提醒、坐在小椅子上敲键盘。每种状态有两张透明 PNG，程序用定时器逐帧切换。

## Windows 运行方法

安装 Python 3.10 或更新版本，在 PowerShell 中进入 `sipcat` 文件夹，运行：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

没有 `py` 命令时，把第一行的 `py` 换成 `python`。

## 使用

- 左键拖动猫；**双击猫或托盘图标打开数据面板**；右键点击打开菜单，菜单最上方也有「数据面板与改名」。
- 「宠物状态」可切换正常、努力工作，也能预览喝水、提醒动画。
- 默认运行约 **55 分钟**后自动提醒；「提醒间隔」可选 50、55 或 60 分钟。
- 提醒气泡中「喝过了」重新计时，播放约 1.6 秒喝水动画，然后自动进入并持续循环「努力工作」动画；「稍后10分钟」延后；「暂停」停止提醒，直到从菜单恢复。
- 每次点击「喝过了」会记录电脑的本地日期与时间；「数据面板与改名」显示今日时间列表、最近 7 天的次数柱状图，并可修改宠物名字。提醒气泡也显示今日次数。柱状图只统计记录次数，不推算饮水量。
- 点「立即测试提醒」可以马上检查气泡和按钮，不必等 55 分钟。
- 隐藏宠物后程序继续在托盘运行；到时会重新显示宠物和提醒气泡。电脑休眠一段时间后，最多显示一条到期提醒，不会补弹一串。

喝水时间、提醒间隔和宠物名字会保存在当前用户的本地应用数据目录，重启后仍在。旧版「水滴伙伴」已有数据库时，SipCat 会继续使用原数据库，保留记录和自定义名字；全新安装使用 SipCat 的数据目录。改名后桌宠提示、气泡标题和托盘提示会立即更新。宠物位置和暂停状态目前不会保存。工作动画在喝过水后自动开始，也可以从菜单手动选择；程序没有自动判断你是否在工作。图片是两帧循环，后续可再增加中间帧使动作更细腻。

## 打包为 Windows `.exe`

请在 **Windows** 上、项目文件夹的 PowerShell 或命令提示符中运行：

```powershell
.\build_windows.bat
```

脚本会安装构建依赖并把程序与 `assets/` 中的图片打包，生成 `dist\SipCat.exe`。它会用**新生成的 exe 自检**宠物图片和数据面板；自检失败时会删除不能交付的 exe。构建成功后，请退出正在运行的旧版水滴伙伴，再运行这个新文件，双击猫打开面板。这是单文件可执行程序，目标电脑运行时无需另装 Python。首次启动可能比直接运行源码慢一些。记录写入当前用户的应用数据目录，不会写进临时解包目录。

若面板仍无法打开，先用源码运行并检查右键菜单；`--windowed` 会隐藏程序的错误输出，可暂时把 `build_windows.bat` 中的 `--windowed` 换成 `--console` 重新构建，从 PowerShell 运行 `dist\SipCat.exe` 查看报错。提交问题时请附上错误文本、Windows 版本和构建脚本的末尾输出。不要上传本地数据库。

GitHub Actions 的 `Build Windows exe` 工作流也会在 Windows 上运行测试、自检并上传 exe 构建产物。它不会自动创建 Release；可以在仓库的 Actions 页面下载成功运行的 artifact。
